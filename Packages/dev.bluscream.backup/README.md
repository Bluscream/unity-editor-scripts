# Bluscream Backup System (`dev.bluscream.backup`)

Automated, flexible backup and restore system for Unity assets, GameObjects, components, materials, and textures.

## Features
- **Asset Backup**: Export CSV manifests with asset paths, sizes, and MD5 hashes.
- **GameObject & Component Backup**: Save and restore GameObject hierarchies and component states.
- **Material & Texture Backup**: Create snapshots of materials and textures.
- **Backup Window**: GUI interface for managing and restoring backups in Unity Editor.

## Dependencies
- `dev.bluscream.common` (v1.2.1+)
